# 戦国思想録（天下往来の中のカードゲーム）

このフォルダ（`card/`）が戦国思想録の本体です。以前は別リポジトリ `s.card` に置いていましたが、天下往来にまとめました（2.108.1）。

- `index.html` … ゲーム本体（単体でも、天下往来の遊戯屋からも同じものを使います）
- `houses/` … 家ごとの札データ(`oda.js` `otomo.js` など)。読み込む順番は `index.html` の `HOUSE_FILES` で決まり、札IDの連番に効くので、順番は変えず新しい家は末尾に足します。家に属さない共通札は `_common.js`
- `img/` … カード絵
- `docs/` … バランス調整用の資料
- `archive/` … 過去のカードデータ
