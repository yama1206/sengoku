# 絵の指示書: 1560年代 四国・奥羽・北陸パック(戦国思想録 v0.42)

## 1. 共通ルール
- **枚数:** 126枚(9家 × 14枚)
- **サイズ・形式:** 576×768px(縦長3:4)、PNG
- **保存先・名前:** `card/img/` フォルダに、下の表の「ファイル名」のとおり保存(例 `e1560e_so_07_ssr.png`)。置くだけでゲームに自動で出ます
- **1つの版につき1枚。** 候補は出さず、そのまま使う
- **画風:** リアル寄りのアニメ調。姫はかわいく、男性武将はかっこよく。AIっぽさ(のっぺり、不自然な光沢)は減らす
- **顔:** 同じ人物はSR/SSRで同じ顔にする。人物ごとに顔の特徴を固定(同じシード・参照画像・同じ特徴文を使う)
- **文字:** 絵の中に文字・家紋の文字・ロゴは入れない(旗や紋は簡略な図形に)
- **構図:** 上半身〜膝上。カード下部に文字枠が重なるので、顔は上半分に置く
- **種類の呼び名:** 以前の「奇襲」は「戦術」に改名済み(表の「種類」は戦術)

## 2. 背景色(思想ごと)
- 創=金 #e0b341 / 義=青 #4a8fe7 / 武=赤 #e0524f / 謀=紫 #a477e0 / 耐=緑 #4cae6a
- 背景のベース色は思想色。家の城や風景を薄く入れてよい

## 3. 版ごとの格差
- **N(武器):** 地味。単色に近い背景、アイテムを大きく1つ
- **R(城・戦術):** シンプル。思想色の背景に主役を置くだけ。豪華にしすぎない
- **SR(武将・姫・大名):** 凝った背景、立ちポーズ、少しの光や気迫の演出
- **SSR(大名・姫のみ):** 一番豪華。SRとは**ポーズを変える**(例: 立ち→戦場で動きのある構図)。金の粒子、光の筋、大きな背景効果。姫はSRとSSRで衣装の華やかさもはっきり差をつける

## 4. 人物・カードごとの指示
- 史実の人物は、当時の肖像画の雰囲気を参考にしつつ現代風に整える
- 澪姫・薄雪姫・彦姫・乃々姫は創作の姫。自由にデザインしてよい(同じ人物はSR/SSRで同じ顔)

## 5. 作業メモ
- 人物ごとに顔の特徴を先に決め、SR→SSRの順に同じ顔で作ると揃いやすい
- 置いたあとはゲームを開いて表示を確認(無い絵は色枠だけが出る)
- 同じ思想の家が2つずつある(義=河野・最上、武=三好・南部、謀=伊達・蘆名、耐=朝倉・能登畠山)。背景は同じ思想色だが、風景(海・雪・山)で家の違いが分かるようにする
